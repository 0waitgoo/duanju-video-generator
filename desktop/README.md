# 短剧成片工作室

Windows 10/11 x64 桌面软件。把短剧创作画布导出的项目 ZIP 转成一集带字幕的 MP4。安装包含 Electron 和 FFmpeg。

## 安装和使用

1. 双击 `Duanju-Studio-Setup-1.4.11.exe`，完成安装后打开桌面或开始菜单中的「短剧成片工作室」。左下角显示当前软件版本。安装包未签名，Windows 可能显示未知发布者。
2. 在「设置」中保存 MiniMax Key。MiniMax H3 需要按量付费 Key，站点要与 Key 一致。使用提示词优化时再填写 DeepSeek Key。测试连接只验证鉴权。
3. 拖入画布「导出项目」产生的 ZIP，或点「导入 ZIP」。在时间线查看分镜、绑定和一致性检查。可选本地配乐。
4. 点「检查并生成整集」，处理阻塞项，核对子段数、提交时长、分辨率和参考图。确认提交后，整集成片区可预览、按计划时长定位分镜并保存 MP4。

[申请 MiniMax Key](https://platform.minimax.io) · [申请 DeepSeek Key](https://platform.deepseek.com)

## 生成与恢复

- 保存 DeepSeek Key 或打开设置时会自动刷新模型。可以保存默认模型，也可在「一致性检查」为本次分析单独选模型。选择支持看图的 Flash 模型后，可附上四宫格和定妆照。核对建议前后内容后勾选应用。
- 在「本段绑定资源」点击「换图」，可从电脑选择人物、场景或道具的参考图，并恢复原图。换图更新本项目后续提交使用的素材。
- 右上角「全屏」或 F11 切换全屏。宽屏时分镜列表换行展示，右侧详情和下方生成队列仍可浏览。

- 点右侧「编辑分镜」修改景别、画面、提示词、运镜或音效，修改后可恢复导入内容。台词与镜头时长沿用画布原值。
- 队列内可独立生成一个子段。480P 小样由 MiniMax 云端生成，完成后下载到本机预览。小样单独显示排队、提交、生成和下载状态，按 MiniMax 资费计费。
- 小样完成后，可在队列或预览窗口点「小样转高清」。本机 FFmpeg 放大后另存 MP4，竖屏 9:16 输出 1080 × 1920，无需再次调用 MiniMax。
- 正式子段的预览也能单独转高清。小样失败但同一子段已有正式版时，可在「处理小样」里直接选「正式版转高清」。
- 转高清成功后，软件会保留一份项目内高清副本，预览自动使用高清。正式子段的高清也会在整集生成检查中列出并用于拼接。可在预览点「看原版」，或在高清窗口点「采用已有高清 MP4」关联旧版软件导出的文件。
- 子段和小样可从原版重新转高清，点击处理方式即开始。成功后采用新结果，可在预览另存 MP4。
- 高清窗口可选择「SeedVR2 3B · AI 转高清」或「FFmpeg 常规放大」。SeedVR2 使用 3B Q4_K_M、CPU 卸载和 VAE 分块，输出保留源音轨，最长边限制为 1920。运行时和模型单独放在 `%LOCALAPPDATA%/DuanjuStudio/SeedVR2`。首次部署可用源码中的 `scripts/install-seedvr2.ps1` 安装，需要 Git、Python 3.12 和支持 CUDA 的 NVIDIA 显卡。下载完成后在本机运行，无需 MiniMax。
- 「设置」按所选站点的 MiniMax 官方视频 V2 文档显示型号与分辨率。大陆站可选 H3、Highspeed、Lite、Max，其中 Highspeed、Lite、Max 支持 480P。Lite 需指定画幅。实际生成权限以所选站点及 Key 为准。选择 480P 后，后续正式子段和整集也会以 480P 提交。 [大陆站文档](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create) [国际站文档](https://platform.minimax.io/docs/api-reference/video-generation-v2-create)
- 整集成片可用 FFmpeg 在本地放大到 1080P 尺寸范围，保持原比例并保留音轨和已烧录的字幕。放大仅改变输出像素，无法恢复源片缺失的细节。

- 识别 `duanju-canvas-export` v1。导入保留原始台词，字幕和提示词均来自原文。重新导入同一画布时保留旧项目，在导入诊断里列出已复用和待生成的子段。复用要求提交参数、提示词和参考图内容一致。
- 已生成的子段可单独重做并比较版本。采用新版后，重新拼接即可更新整集。字幕、原生音轨、拟音和配乐音量可以在项目内调整，也可先试听配乐。
- 20 秒四镜段按前后各两镜拆段。遇到只有一镜、或拆分后无法同时满足每子段至少两镜且不超过 15 秒的情况，工作室会提示回画布调整。少于 4 秒的可用子段按 4 秒提交，拼接时按分镜时长裁切。
- 四宫格、定妆照和设定图走 MiniMax H3 V2 参考图模式。支持 PNG、JPEG、WEBP 包内素材。示例包的 1×1 图片供导入和本地流程验证。正式生成时，MiniMax 要求参考图边长 256–5760 像素，宽高比 0.4–2.5。 [MiniMax H3 视频生成指南](https://platform.minimax.io/docs/guides/video-generation)
- 提示词工作台允许逐镜精简画面与运镜。台词由画布数据附入，手动编辑与 DeepSeek 都不能改写台词字段。提示词优化默认使用 `deepseek-flash`。如果旧设置里保存了已停用的模型名，可在设置刷新模型列表并选择现行模型。 [现行模型](https://api-docs.deepseek.com/quick_start/pricing/)
- 关闭窗口会退出工作室。本地保存队列、提交参数与远端任务 ID，重新打开时恢复查询和下载。提交后未收到 ID 时，队列会要求核对 MiniMax 记录。可输入已有任务 ID 恢复查询，或确认重新提交。
- 默认 9:16、768P、并发 2、关闭 H3 原生声音。转场可选短叠化或直接切换。分镜音效由本地合成音类按字段关键词匹配，背景配乐使用选中的本地文件。软件没有配音入口。
- FFmpeg 对子段做统一画幅、编码和时间轴，烧录字幕，并混入选定音轨。合成失败可重新拼接。已经生成的子段可以预览或单独保存。
- 项目、音频、下载和队列记录均存在 Windows 用户数据目录下。Key 由 Windows DPAPI 加密，只向对应服务商鉴权，设置界面显示已保存 Key 的末 4 位。点生成时会把所用提示词和参考图发给 MiniMax。点 DeepSeek 优化时会把画面和运镜说明发给 DeepSeek。合成、混音、字幕和预览在本地执行。桌面应用不开放 HTTP 端口。

## 常见问题

| 提示 | 处理 |
| --- | --- |
| 1004 / HTTP 401 | 鉴权失败。检查 Key、站点和按量付费权限，保存后可恢复队列。 |
| 创建任务返回 2013 | MiniMax 拒绝了请求参数。打开该子段的处理窗口，记录错误码和 MiniMax 请求 ID（若已返回）。 |
| 查询任务返回 2013 或任务已过期 | 远端任务不存在或过期。单独重试对应子段。 |
| 提交结果待核对 | 先检查 MiniMax 任务记录。有 ID 就输入后继续查询，确认没有原任务时可重新提交。 |
| 缺参考图 / 超过 9 张 / 单图超过 30 MB / 请求超过 64 MB | 根据一致性检查和任务提示调整画布素材，再重新导出。 |
| DeepSeek 提示词优化不可用 | 保留原提示词，检查模型和 Key。可在设置切换到现行 Flash 模型。 |
| 网络或磁盘空间不足 | 检查网络或清理空间。查询、下载失败后可重试原任务，合成可单独重跑。 |

## 从源码构建

运行安装后的软件不需要 Node.js。以下命令仅供构建和复测，在 Windows x64、Node.js 24 环境执行。

```powershell
npm.cmd ci
pwsh -NoProfile -File build/prepare-ffmpeg.ps1
npm.cmd start
npm.cmd run dist
```

安装包输出到 `release/`。FFmpeg 准备脚本下载固定版本并验证 SHA-256；已有归档时可传 `-Archive <路径>`。安装包内含 Gyan FFmpeg 8.1.2 Full Build 的执行文件与许可证。 [FFmpeg 构建与源码入口](https://www.gyan.dev/ffmpeg/builds/) · [FFmpeg 8.1.2 源码](https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz)

复测交接包时，把 `DUANJU_HANDOFF` 环境变量设为解压后含 `示例包`、`分镜`、`剧本` 的目录，运行 `npm.cmd test`。可设置 `DUANJU_TEST_MP4` 为测试成片的完整输出路径。原始交接素材随用户交接包提供。
