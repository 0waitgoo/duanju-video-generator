# cinema-dna-21x9x3（开发参考文档）

来源：cinema-dna-21x9x3 v3.2.3（https://github.com/dacnay816y62-hub/cinema-dna-21x9x3），
一份给 AI 助手看的电影感分镜与视频提示词规则书。

## 这份文件是干什么的

- **桌面程序运行时不读取、不执行这里的任何文件。** 这里是开发参考文档，
  供维护桌面软件的人（或 AI）阅读后，把规则翻译成代码与提示词。
- 核心文件：`SKILL.md`；`references/` 是分项规则（导演工作流、连续性与状态、
  运镜协议、提示词写作、中文固定模板、验收等）；`assets/提示词模板/` 是完整视频提示词模板。

## 已经落地的对接（画布 → 桌面）

- 画布导出包（格式 `duanju-canvas-export` v1）每镜带四组可选字段：
  `director`（主要事件、观看立场、信息落点、视线流量、关系压力）、
  `ledger`（功能、镜前、镜后、依赖镜号）、`state`（本镜状态，一行简表）、
  `acceptance`（通过 / 失败 / 未检查、未通过项、证据、补跑次数）。
- 桌面 `src/project.js`：`normalize()` 原样透传这四组字段；
  `prompt()` 每镜追加「导演：…」与「本镜状态：…」；
  `inspect()` 对验收未通过的镜报红，点名未通过项与补跑次数。
- 桌面 `ui/app.js`：分镜详情有字段时显示导演判断、本镜状态、画布验收结果。
- 老包没有这些字段时，行为不变，可正常导入。

## 明确不采用的部分

- 三联 / 九镜外部拼版：画布保留四宫格（一段一张 1:1 图，2×2 按镜号），不改独立出图再拼版。
- 默认画幅 2.39:1：画布默认 9:16，构图规则按竖屏理解。
- Seedance 2.5：桌面视频生成走 MiniMax H3（V2 接口），提示词按 H3 结构组织。
